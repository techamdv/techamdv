* 🔌 Integrated external telecom services into backend workflows for automated provisioning and activation.
* 🧩 Designed backend workflows capable of supporting multiple white-label ESIM businesses from a shared platform.

**Tech:** SQL · Multi-Tenant Architecture · RBAC · Payment Gateway Integration · Vendor Wallets · Commission Systems · Telecom APIs · Automation
